# 🎯 Number Guessing Game

A clean, responsive number guessing game built using **HTML5, CSS3, and JavaScript**.

🚀 **[Play the Live Demo Here](https://kratigupta04012008-ui.github.io/mini-js-projects/)**

---

## 🎮 How to Play
1. The game selects a random secret number between **1 and 100**.
2. Enter your guess in the input box and click **Guess** (or press **Enter**).
3. You will receive feedback on whether your guess is **Too High** or **Too Low**.
4. You have **10 attempts** to guess the correct number!

---

## 🛠️ Features
* **Input Validation:** Prevents invalid inputs or out-of-range numbers.
* **Attempt Tracking:** Displays remaining attempts dynamically.
* **Keyboard Support:** Submit guesses instantly by hitting `Enter`.
* **Game Reset:** Play again seamlessly without refreshing the browser.

---

## 💻 Tech Stack
* **HTML5** - Structure and layout
* **CSS3** - Dark theme styling and layout alignment
* **JavaScript (ES6)** - DOM manipulation, state management, and game logic
